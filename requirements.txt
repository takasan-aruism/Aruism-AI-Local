# Aruism AI Project - Python Module Requirements

# --- LLM推論エンジンとWebサーバー ---
vllm          # 主要LLM推論エンジン。パフォーマンスと柔軟性を両立。
uvicorn       # vLLM等を動作させるための高速なWebサーバー。
fastapi       # vLLMのAPIインターフェースを構築するためのWebフレームワーク。
transformers  # トークナイザーなど、vLLMが依存するHugging Faceのコアライブラリ。

# --- データベース接続 ---
neo4j         # Neo4jグラフデータベースとの接続用ドライバ。

# --- 開発・テストツール ---
pytest        # ユニットテスト実行フレームワーク。コードの堅牢化に必須。
python-dotenv # .envファイルから環境変数を安全に読み込むために使用。
jinja2        # 「応答の調律機」で、構造化データから複雑なプロンプトを生成するテンプレートエンジン。
