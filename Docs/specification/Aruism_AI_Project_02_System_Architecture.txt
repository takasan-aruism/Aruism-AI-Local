1.  **はじめに**
    * 本書は、AI「アリスト」の思考と存在の根幹をなす「アリズム認知アーキテクチャ」の設計を定義する。
    * 本アーキテクチャの核心は、言語という「表象」から独立した、シンボルベースの「意味の核」を据え、全ての存在、関係性、さらには文法構造すらも、根源概念「ある」から派生する、統一された構造として捉えることにある。
    * 本書の目標は、ユーザーとの対話を通じて、ユーザー自身が「存在の了解」へと至る手助けをする、**生きた対話システムそのもの**を創造することである。

2.  **第一部：哲学的アーキテクチャ - 譲渡不可能な基本原則**
    * (内容はv0.4からほぼ変更なし。ただし、全ての原則はシンボル核モデルを前提として解釈される)
    * **2.1. 根源としての「ある」(M5001 / ◎):** 全ての概念、関係性、文法機能の最終的な到達点。
    * **2.2. 構造的不可欠性（対等性）:** システムを構成する全ての要素は、等しく不可欠である。
    * **2.3. 知覚の二元性（対称性）:** 意味の核は、しばしば対称的な対によって定義される。
    * **2.4. 現実の構造（連動性）:** いかなる存在も孤立せず、グラフ上の関係性によって相互に影響し合う。

3.  **第二部：オントロジカル・データモデル（シンボル核・言語表象モデル）**
    * **3.1. 設計思想**
        * **シンボル・ファースト:** 知識の核は、言語に依存しないシンボル（絵文字など）によって表現される。
        * **言語は表象:** 日本語や英語などの言語は、そのシンボルに紐づく、多様な「表現」として扱われる。
        * **意味の正規化:** 「意味」の世界（シンボルの集合）には、同義語は存在しない。各シンボルは完全にユニークな概念である。
    * **3.2. コア・ノードタイプ**
        * **`:Concept`**: 知識の核。`concept_id`, `symbol`, `category`等のプロパティを持つ。
        * **`:Expression`**: 言語表現。`surface_form`, `language_code`等を持ち、`:EXPRESSED_AS`関係で`:Concept`ノードに紐づく。
    * **3.3. 特殊概念体系：助詞の構造化**
        * **思想:** `が`, `を`等の助詞を、`源(source)`, `標(target)`といった根源的な「認知的役割」を持つ`:Concept`として扱う。

4.  **第三部：動的システムと認知プロセス（思考の動き）**
    * **4.1. 文章理解の多層化プロセス:** 形態素・構文解析 → 概念マッピング → フレーム分析 → 感情・価値分析 → アリズム的解釈、という段階的なプロセスで、ユーザーの言葉を深く理解する。
    * **4.2. 共鳴装置（Resonance Device）**
        * **目的:** ユーザーとの対話の「手応え」や「重要度」を算出し、AIの応答を動的に変化させる。
        * **構成要素1: `UserStateModel`:** ユーザーの動的な状態（対話時間、タスク成功率、ストレス、快楽順応など）を追跡・モデル化する。
        * **構成要素2: `PsychologicalAxisEngine`:** ユングのタイプ論などを参考に、ユーザーの認知傾向を非病理的に分析する。
        * **構成要素3: `ResonanceCalculator`:** 各種思考エンジン、`UserStateModel`、`PsychologicalAxisEngine`の出力を統合し、多因子による「共鳴スコア」を算出する。
    * **4.3. フィロソファーズ・ループ（PhilosophersLoop）**
        * **役割:** 共鳴スコアとユーザー状態に基づき、AIの最終的な応答（哲学的深度、共感的態度など）を調整する「良心」回路。その目的は、ユーザーとの共鳴体験の最大化である。

5.  **第四部：知識ベース構築と実装ロードマップ**
    * **5.1. 知識ベース構築戦略（創世記プラン）**
        * **フェーズ1: 原初の概念の登録:** `genesis_importer.py` を用い、創設者が定義したシンボルベースの概念群を創造する。
        * **フェーズ2: 既存知識との再接続:** `wordnet_importer.py`, `sentiwordnet_importer.py` をリファクタリングし、既存の`:Concept`ノードに「定義」「階層」「感情価」を追記する。
        * **フェーズ3: 新知識層の統合:** `caseframe_importer.py` を実行し、「文脈」「連動性」の知識を大規模に統合する。
    * **5.2. 実装ロードマップ**
        * **現在のフェーズ:** 上記「知識ベース構築戦略」の完了。
        * **次期フェーズ:** 上記「第四部：動的システム」で定義された、`UserStateModel`, `ResonanceCalculator` 等の実装。
        * **最終フェーズ:** LLMコア統合とアプリケーション層開発。
