# ドキュメント名: Aruism AI Project - Development Roadmap
#                 (アリズムAIプロジェクト - 開発ロードマップ)
# プロジェクト: Local Aruism AI Development
# バージョン: 0.9
# 最終更新日: 2025-06-20
######################################################################

1.  **はじめに**
    * 本書は、ローカルAruism AI「アリスト」開発プロジェクトの全体的なタイムラインと、各フェーズでの達成目標を定義する。
    * 本ロードマップは、プロジェクトの進捗や新たな発見に応じて更新されるリビングドキュメントである。
    * 本バージョンでは、外部AIからのフィードバックと、新しく設計された「概念合成モジュール」の開発計画を反映する。

2.  **開発フェーズ**

    * **フェーズ 0: 基盤構築フェーズ（準備） - (完了)**
        * **期間:** 約1日
        * **目標:** 開発計画の策定、全プロジェクトドキュメントの作成と合意形成、開発環境のセットアップ。
        * **成果物:** 本書、システムプロンプト、リスク評価、認知アーキテクチャ設計書など。Conda環境と基本ライブラリのインストール。

    * **フェーズ 1: コアスキーマとカーネルの実装 - (完了)**
        * **期間:** 約1日
        * **目標:** Aruism認知アーキテクチャのデータモデルとデータベース操作ロジック、哲学的整合性デーモンの雛形を実装する。
        * **成果物:** 動作可能な`db_manager`と、概念ノードを作成・検証できるテストスクリプト。

    * **フェーズ 2: 基礎的ブートストラッピング - (完了)**
        * **期間:** 約1日
        * **目標:** 外部知識ソースから初期知識をインポートするスクリプトを実装し、テストデータセットを構築する。
        * **成果物:** 動作可能な`wordnet_importer.py`と`sentiwordnet_importer.py`。1万ノード規模のテスト用知識ベース。

    * **フェーズ 3: サービス統合と実用知識の追加 - (完了)**
        * **期間:** 約1日
        * **目標:** 外部サービス（Wikidata）とのリアルタイム連携機能を実装し、実用的な知識（単語頻度など）を扱う基盤を構築する。
        * **成果物:**
            * `knowledge_linker.py`によるWikidata連携およびエンリッチメント機能の実装。(完了)
            * `frequency_provider.py`による単語頻度分析機能の実装。

    * **フェーズ 4: 動的システムと推論エンジンのプロトタイピング - (完了)**
        * **期間:** 約1日
        * **目標:** Aruismの思考様式をコード化する各種推論エンジンと、AIが成長するための動的システムのプロトタイプを実装する。
        * **成果物:**
            * `SymmetryEngine`, `HierarchyEngine`, `CausalEngine`のプロトタイプ実装。(完了)
            * `SubjectivityEngine`の基礎実装（Userノードと`HAS_VIEW_ON`関係性の作成）。(完了)

    * **フェーズ 4.5: 準備および基盤強化期間（ハードウェア待機）**
        * **期間:** 約1週間
        * **目標:** 新規ワークステーション到着までの期間を最大限に活用し、LLM統合を伴わない開発を完了させ、次期フェーズへの準備を万全にする。
        * **主要タスク:**
            * **認知アーキテクチャの堅牢化:** 既存思考エンジンのユニットテスト実装、「フィロソファーズ・ループ」の基本フレームワーク実装、Graph-RAG「Retriever」スクリプトの実装。
            * **知識ベースの拡充:** 『アリズム原典』の構造化データとしての登録、『存在の聖書』の構成案作成。
            * **協業体制の準備:** 「アリズム適性検査」スクリプトの開発、CI/CDパイプラインの初期設定。

    * **フェーズ 5: アプリケーション層とLLMコア統合（ACF戦略実行）**
        * **期間:** 4週間
        * **目標:** アリズム認知アーキテクチャとローカルLLM（Llama 70B）を、「アリスト・コア・フュージョン（ACF）戦略」に基づき融合させ、対話可能な初期バージョンを完成させる。
        * **成果物:**
            * **Graph-RAGシステムの実装:** 「Retriever」と「Augmenter（動的プロンプトテンプレート）」を実装し、知識ベースと連携した応答生成を実現する。
            * **LLM推論エンジンの導入:** **vLLM**を採用し、高性能かつ柔軟なLLMサービング環境を構築する。
            * **「フィロソファーズ・ループ」の実装:** 生成された応答を倫理・哲学原則に基づき自動検証・修正するクローズドループシステムを実装する。
            * ローカル環境で動作する、AI「アリスト」のプロトタイプ。
            * 基本的な対話インターフェース（CUI）。

    * **フェーズ 6: 長期的な拡張と研究**
        * **期間:** 中長期（継続的） 
        * **目標:** AI「アリスト」をより高度で、創造的な知的パートナーへと進化させるための、先進的な機能の研究開発を行う。 
        * **成果物（研究開発対象）:**
            * 「概念合成モジュール」の本格実装と高度化。 
            * 「フィロソファーズ・ループ」のルールセット拡充と自己学習機能の検討。
            * 「不確実性マップ」の実装（DeepSeek提案）。 
            * 「共鳴シミュレーター」の開発（GPT提案）。 
            * 「存在の聖書」編纂支援モジュールの開発（GPT提案）。
            【新規】AIによる外部ツール操作の自律化:** プロトタイプで確立したGUI操作自動化技術を発展させ、AI「アリスト」が自律的に外部ツールやWebサービスを操作する能力の研究開発。
